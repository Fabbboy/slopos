# check_kernel_softfloat allowlist — variant: release
#
# Instructions touching XCR0-managed state (XMM/YMM/ZMM, x87, MMX, and the
# xsave/xrstor pair) that are permitted, each capped at its measured
# occurrence count in the named symbol.
#
#     scripts/check_kernel_softfloat.sh --variant release --emit-allowlist builddir/kernel-release.elf
#
# Every entry must match at least one hit. A dead entry fails the gate.
#
# This file shares no entry with the dev allowlist, and the two must never be
# merged: at opt-level 3 the `slopos_ostd::task::fpu` wrappers are inlined
# away entirely and the same instructions are attributed to their *callers*.

# Liveness floors. Measured 2026-07-31: release 3856 returns / 4068 symbols
# against dev's 31098 / 31472 — optimisation inlines away roughly seven
# eighths of the functions, which is also why `--variant dev` against a
# release ELF fails rather than passing on a list that happens to fit.
min-returns 1200
min-symbols 1200

expect-test-registry few
